# UBaseAbilitySystemGlobals

## Overview
`UBaseAbilitySystemGlobals` extends the global ability system to include project-specific functionality.

## Properties
- **DeadTag**: Cached tag for the "Dead" state.
- **KnockedDownTag**: Cached tag for the "Knocked Down" state.
- **InteractingTag**: Cached tag for the "Interacting" state.
- **InteractingRemovalTag**: Cached tag for removing the "Interacting" state.
