
# UBaseAbilityCost

## Overview
`UBaseAbilityCost` is the base class for defining costs associated with gameplay abilities.

## Properties
- **bOnlyApplyCostOnHit**: If true, the cost is only applied if the ability hits successfully.

## Methods
- **CheckCost**: Checks if the cost can be paid.
- **ApplyCost**: Applies the cost to the target.
