# CustomCameraTypes

## Overview
`CustomCameraTypes` contains additional types and enums used throughout the custom camera system. These types provide additional functionality and customization options for camera behavior.

## Types
### ECameraModeBlendFunction
An enum that defines the blending functions used for transitioning between camera modes.

- **Linear**: A linear blend between camera modes.
- **EaseIn**: A blend that starts slow and accelerates.
- **EaseOut**: A blend that starts fast and decelerates.
- **EaseInOut**: A blend that starts slow, accelerates, and then decelerates.

## Usage
These types are used throughout the custom camera system to provide additional functionality and customization options for camera behavior.
